📊 Healthcare UX Architecture & Tableau Layout Specification

Comprehensive design blueprint, visual hierarchy matrix, WCAG 2.1 AA accessibility guidelines, and Tableau dashboard container layout specs.

📱 Mobile Ergonomics & Thumb Zone

  • Bottom-Anchored CTA: Primary actions placed within natural single-thumb arc (bottom 40% of viewport).
  • Touch Targets: All interactive tags, chips, and buttons maintain minimum 48×48px dimensions.
  • Type Scale: Title 18-20px bold, Subtitle 14px, Body 14px, Badges 12px for maximum legibility on 375-430px screens.

🎯 Correlation Scoring Algorithm

Formula implemented:

Match % = (Matched / DiseaseTotal * 65%) + (Matched / UserSelected * 35%)
  • High Match (≥70%): Emerald Green (#10B981) gauge.
  • Moderate Match (40-69%): Amber (#F59E0B) gauge.
  • Low Match (<40%): Slate (#94A3B8) gauge.

♿ WCAG 2.1 AA Accessibility Audit

  • Color Contrast: Minimum 4.5:1 text-to-background contrast ratio across dark & light themes.
  • Keyboard Focus: High-visibility 3px primary glow focus outline on all interactive inputs.
  • Screen Readers: aria-live="polite" on dynamic result containers and aria-pressed state management.

📈 Tableau Dashboard Container Blueprint

  • Top Container (Tiled, 100px height): Emergency Triage Alert Banner & Patient Profile Filter.
  • Left Pane (Fixed 350px): Interactive Symptom Selector (Custom HTML/JS Extension / Filter Parameter).
  • Center Matrix (Flex Auto): Differential Diagnosis Treemap / Scatterplot (Correlation Score vs Severity).
  • Right Pane (Fixed 300px): Specialist Referral Network Map & Appointment Booking Action Card.
