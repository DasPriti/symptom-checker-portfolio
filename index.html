📊 Lead Healthcare UX Architecture & Disease Likelihood Spec

Complete design blueprint, visual hierarchy matrix, WCAG 2.1 AA accessibility guidelines, and Tableau dashboard container layout specs.

📱 Mobile Ergonomics & Thumb Zone

  • Bottom-Anchored CTA: Primary actions placed within natural single-thumb arc (bottom 40% of viewport).
  • Touch Targets: All interactive tags, chips, and buttons maintain minimum 48×48px dimensions.
  • Type Scale: Title 18-20px bold, Subtitle 14px, Body 14px, Badges 12px for maximum legibility.

🎯 Disease Likelihood Percentage Formula

Formula implemented:

Likelihood % = (Matched / DiseaseTotal * 65%) + (Matched / UserSelected * 35%)
  • High Likelihood (≥75%): Emerald Green (#10B981) gauge.
  • Moderate Likelihood (45-74%): Amber (#F59E0B) gauge.
  • Low Likelihood (<45%): Slate (#94A3B8) gauge.

♿ WCAG 2.1 AA Accessibility Audit

  • Color Contrast: Minimum 4.5:1 text-to-background contrast ratio across dark & light themes.
  • Keyboard Focus: High-visibility 3px primary glow focus outline on all interactive inputs.
  • Screen Readers: aria-live="polite" on dynamic result containers.
