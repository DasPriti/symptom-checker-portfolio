## 📱 About the Project

**MediGraph** is a clean, modern, mobile-first healthcare UX app designed to help patients map symptoms to medical conditions and connect with recommended specialist physicians.

### ✨ Key Features
- **🔍 Interactive Symptom Selector Widget**: Auto-complete search across 655+ symptoms, instant tag selection pills, and one-tap quick-chips.
- **📊 Diagnostic Correlation Summary Cards**: Real-time correlation scoring gauge (High/Moderate/Low), triage severity badges (*Emergency*, *Urgent*, *Routine*), and transparent matched vs unmatched symptom breakdown.
- **👨‍⚕️ Specialist Recommendation Hierarchy**: Direct mapping of specialists (`Cardiologist`, `Endocrinologist`, `Neurologist`, `Pulmonologist`, etc.) with action CTAs.
- **♿ WCAG 2.1 AA Compliant**: High contrast dark theme, accessible 48px touch targets, and ARIA screen reader support.
- **🖥️ Dual Viewport & Tableau Specification**: Toggle between Mobile Smartphone Frame view and Enterprise Tableau Dashboard layout view.
